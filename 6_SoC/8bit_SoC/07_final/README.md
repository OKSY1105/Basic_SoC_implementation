# 최종 산출물 — 준비 위치

최종 시스템 설명, 블록도/ISA/주소 맵/포트 시간표, 재현 가능한 검증 로그, FPGA 합성 자원·타이밍, PC→LCD 시연 자료, 한계와 개선점을 보관한다.

현재 전체 SoC·보드 시연·FPGA 타이밍의 최종 증빙은 없다. 생성 로그·비트스트림은 build에 두고 재현 명령과 필요한 요약/공유할 증빙을 선별한다.
