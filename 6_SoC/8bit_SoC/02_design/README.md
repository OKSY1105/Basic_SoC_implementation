# 시스템 설계 진입점

| 문서 | 다루는 결정 |
|---|---|
| [CPU](cpu.md) | 기존 ISA·파이프라인·외부 포트와 원본 연결 |
| [RAM](ram.md) | DRAM 행동 모델·바이트 제어기·실물 경계 |
| [UART](uart.md) | 기존 FIFO/상태와 MMIO 변환에서 남은 일 |
| [BUS](bus.md) | 주소·선택·대기·오류·응답 중복 방지 |
| [공유 인터페이스](interfaces.md) | 폭·주소 단위·현재 계약과 미결 |

설계 순서는 전체 계약을 먼저 맞추고 기존 블록을 작은 조합으로 시험하는 방식이다. 현행 CPU를 분리 포트에서 공유 메모리 구조로 바꾸는 결정은 이번 경로 정리에 포함하지 않는다.

공용 모듈 저장 위치와 SoC 연결 책임은 [소유 경계](source_layout.md)를 먼저 따른다.
