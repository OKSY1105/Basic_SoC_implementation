# 전체 시나리오 시험 계획 — 미실행

| 입력/조건 | 확인할 기대 결과 |
|---|---|
| 10 + 20 | 30 |
| 10 - 20 | -10 |
| -128 + -128 | -256 |
| -128 × -128 | 16384 |
| 10 ÷ 20 | 몫 0, 나머지 10 |
| -128 ÷ -1 | 16bit 몫 128, 나머지 0 |
| 음수의 나눗셈 | 반올림/나머지 부호 규약 확정 뒤 참조값 생성 |
| 0으로 나누기 | 정한 오류 코드, hang 없음 |
| 범위 밖/잘못된 입력 | 정한 오류 응답, 다음 요청 복구 |
| 연속 요청/수신 지연/reset | 응답 중복·유실·LCD의 낡은 결과 처리 검사 |

시뮬레이션, 실제 UART 선로, STM32/LCD 결과는 각각 기록한다. 프로젝트 폴더 구성만으로 위 결과가 검증된 것은 아니다.
