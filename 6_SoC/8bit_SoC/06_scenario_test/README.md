# 전체 시나리오 시험 — 실행 범위와 남은 일

v2 1단계(2026-11-24)는 통합·보드 TB 자체 시뮬레이션까지 완료했고 VR-016·보드 실물·MSPM0는 미실행이다. v1의 보드 결합 결과와 구분한다. 상세 결과는 [통합 TB](../tb/soc/README.md)·[보드 TB](../fpga/boards/zybo/README.md)·[PC 도구](../pc_tools/README.md)에 있다.

| 입력/조건 | 확인할 기대 결과 |
|---|---|
| 10 + 20 | 30 |
| 10 - 20 | -10 |
| -128 + -128 | -256 |
| -128 × -128 | 16384 |
| 10 ÷ 20 | 몫 0, 나머지 10 |
| -128 ÷ -1 | 16bit 몫 128, 나머지 0 |
| 음수의 나눗셈 | 몫은 0 방향, 나머지는 A 부호([계산기 규약](../02_design/calculator.md)) |
| 0으로 나누기 | `ERR DIV0`, hang 없음 |
| `-2,15` POW / `2,15` POW | `POW:-32768` / `ERR OVER`, A·B 유지 |
| `0,0` POW·GCD·SQR | `POW:1`·`GCD:0`·`SQR:0` |
| `-128,0` GCD / `127,9` SQR | `GCD:128` / `SQR:11` |
| `2,-1` POW / `-1,0` SQR | `ERR RANGE` |
| 범위 밖/잘못된 입력 | 정한 오류 응답, 다음 요청 복구 |
| 연속 요청/수신 지연/reset | 응답 중복·유실·LCD의 낡은 결과 처리 검사 |

시뮬레이션, 실제 UART 선로, STM32/LCD 결과는 각각 기록한다. 프로젝트 폴더 구성만으로 위 결과가 검증된 것은 아니다.
